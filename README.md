# cellblock

**CellBlock** is a cross-platform digital wellbeing app designed for high-accountability usage. Unlike standard blockers, CellBlock enforces a "Default Deny" policy where the internet is blocked by default, allowing only specific exceptions. It features a flexible time budget that synchronizes across devices and requires a secondary user ("Warden") to authorize changes or unlock the device after time expires. It also allows a number of always on apps such as utility apps (e.g. Google Maps) and optinially less distracting audio apps (Spotify, Audible)
